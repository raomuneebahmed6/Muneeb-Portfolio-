# Client review drafts

These are **drafts only**. Send each one to the client, let them change it, and add it to the
website only after they say OK. Then paste the approved text into `testimonials` in
`src/config/site.ts`, for example:

```ts
export const testimonials = [
  { name: "Client Name", company: "Zoom Haier Store, Lahore", quote: "Approved review text…" },
];
```

The "What clients say" section appears on the site automatically once the list has entries.

## WhatsApp message to send each client

> Assalam o Alaikum! Main apni portfolio website bana raha hoon aur usme aapka project
> (website link) dikhana chahta hoon. Kya aap 2–3 lines ka chhota sa review de sakte hain?
> Maine neeche ek draft likha hai, aap isay badal sakte hain ya apne alfaaz mein likh dein.
> Aur kya main aapka naam aur company ka naam review ke sath likh sakta hoon? Shukriya!
